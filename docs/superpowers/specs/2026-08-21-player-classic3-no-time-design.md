# 经典界面 3-无时间设计

## 目标

新增一套仅供玩家端使用的 H5 聊天皮肤，后台名称为“经典界面 3-无时间”。新皮肤以当前 `chat_page3.html` 为基础，移除消息时间及其布局占位，同时保持原经典界面 3 不变。

## 范围

- 新模板文件：`static/templates/default/chat_page3_notime.html`。
- 后台皮肤选项：`经典界面 3-无时间`。
- 模板白名单增加 `chat_page3_notime.html`。
- 仅影响玩家 H5 聊天页面；不修改客服后台对话页面。
- 不修改现有 7 套玩家皮肤。

## 界面结构

### 客服发给玩家的消息

- 删除 `formatTime(v.time)` 和对应的 `.chatTime` 容器。
- 保留客服名称。
- 客服名称使用紧凑信息行，直接位于消息气泡上方，不继承时间容器的边距。

### 玩家自己发送的消息

- 删除气泡上方独立的 `.chatTime` 行。
- 保留气泡下方原有的“已读/未读”状态。
- 消息气泡不再为时间预留垂直空间。

## 行为保持

新模板完整继承当前经典界面 3 的消息收发、历史补拉、断线重连、消息去重、图片与文件上传、国际化和移动端兼容逻辑。除消息时间布局外，不改变数据流或交互行为。

## 测试与验收

- 白名单接受 `chat_page3_notime.html`。
- 后台设置存在“经典界面 3-无时间”选项。
- 原 `chat_page3.html` 仍包含时间渲染，证明原皮肤未被修改。
- 新模板的消息循环不包含 `formatTime(v.time)` 或 `.chatTime` 时间容器。
- 新模板保留客服名称、消息内容、已读状态和消息可靠性标记。
- 浏览器切换新皮肤后，客服消息与玩家消息均无时间文字和时间占位。
- 完整 Go 测试、构建和 `git diff --check` 通过。
